# Puce

Une étiquette courte : durée, modalité, outil.

Ajout intentionnel. Style `signal` en capitales pour les métadonnées ; variante `puce--outil` en `code` pour les noms de bibliothèques.

## Ce que vous fournissez

```html
<ul class="puces">
  <li class="puce">6 semaines</li>
  <li class="puce puce--outil">scikit-learn</li>
</ul>
```

## Règles

- Rayon `rayon-pilule` ; bord `trait-fin` en `ligne-forte` ; texte `texte-doux`.
- Une puce n'est pas un bouton : si elle mène quelque part, faites-en un lien avec la même classe.
