# Bouton

L'action en texte : une pilule en Rajdhani, avec une variante principale au bord prisme.

Ajout intentionnel : les démos d'origine n'avaient que des boutons-icônes.

## Ce que vous fournissez

```html
<a class="bouton bouton--prisme" href="#chapitre-1">Commencer le chapitre 1</a>
<button type="button" class="bouton">Voir les mini-projets</button>
```

- `bouton--prisme` : l'action principale (une par zone). Le prisme borde un fond `surface`, le texte reste en `texte`.
- `bouton--discret` : action secondaire sans bord (« Recommencer »).
- `bouton--petit` : 36 px de haut, pour les listes d'exemples.

## Règles

- Hauteur 44 px minimum ; bord `trait-controle` en `ligne-forte` ; rayon `rayon-pilule` ; style `signal-l`.
- Le libellé dit ce qui va se passer, à l'infinitif ou à l'impératif : « Examiner la règle suivante ».
