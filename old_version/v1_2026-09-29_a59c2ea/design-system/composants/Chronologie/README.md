# Chronologie

Une suite datée, lue de haut en bas : l'histoire d'un domaine, les étapes d'un projet.

Ajout intentionnel. Les points reprennent l'anneau des démos d'origine.

## Ce que vous fournissez

```html
<ol class="chronologie">
  <li><span class="chrono-date">1950</span>
    <div class="chrono-corps"><p class="chrono-titre">Le test de Turing</p><p>…</p></div></li>
</ol>
```

## Règles

- Seulement pour une vraie séquence chronologique.
- Dates en `signal` 19 px, `tabular-nums` ; filet `ligne` ; anneau `texte` sur `fond`.
